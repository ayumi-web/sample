# stamps/ — 本物スタンプ画像の置き場

`stamps.html` が自動でSVG版から差し替えて表示します。

## 画像の条件（LINE Creators Market）

- **透過背景のPNG**
- 1枚 = 1スタンプ
- サイズ：横370px × 縦320px 以内（偶数ピクセル推奨）
- 余白：周囲に約10pxの余白を空ける

## 入れ方

1. このフォルダ（`stamps/`）に上の名前でPNGをアップロード
2. `stamps.html` を開くと、入れた分だけ自動で本物に差し替わる
   （入れてないものは私のSVG版のまま表示）
